# Пробка во дворе

Первый самодостаточный HTML5-прототип игры без внешних зависимостей.

## Запуск

Из папки проекта:

```bash
python3 -m http.server 5173
```

Открыть:

```text
http://localhost:5173/probka-game/
```

Если запускать из папки `probka-game`, открыть:

```text
http://localhost:5173/
```

## Проверка уровней

```bash
node probka-game/tools/validate-levels.js
node probka-game/tools/analyze-levels.js 30000
node probka-game/tools/validate-daily-levels.js 120
```

## Генерация черновиков уровней

```bash
node probka-game/tools/generate-level-candidates.js 6 27
```

## Что уже есть

- главное меню;
- выбор уровней;
- ежедневный сгенерированный 14x14 hard-уровень с проверкой проходимости: карманы, горизонтальные замки, вертикальные блокеры, 26 машин и 12 препятствий;
- недельная лента daily и серия прохождений с бонусом;
- гараж со скинами красной машины за монеты;
- скины имеют отдельные паттерны, бейджи и акценты, а не просто перекрашивают обычную машину;
- обычные машины визуально различаются: такси, фургоны, доставки, универсалы и компактные машины;
- ежедневные миссии с наградами;
- подсказки статуса на главном экране: daily-награда, серия, готовые миссии;
- 60 пересобранных campaign-уровней в 5 паках;
- вся основная campaign теперь на 6x6 classic Rush Hour-логике: обучение 2-6 ходов, середина 8-36, финал 52-60;
- финальный пак "Двор без надежды" построен на classic Rush Hour hard-раскладках из базы Michael Fogleman (`https://www.michaelfogleman.com/rush/`, MIT: `https://github.com/fogleman/rush`);
- паки 2-4 собраны из solver-generated и Fogleman-derived classic-раскладок с проверкой `minMoves` и `revisits`;
- drag/swipe машин;
- плавные анимации движения и bump при заблокированном движении;
- столкновения;
- лимит ходов на каждый уровень;
- пошаговые actors сохранены в движке и daily/черновиках, но временно убраны из main campaign до actor-aware shortest solver;
- победный sequence при выезде целевой машины;
- звезды по ходам;
- монеты;
- localStorage прогресс;
- WebAudio-звуки без внешних файлов и mute-state;
- подсказки с подсветкой блокирующей машины/линии выезда;
- заглушки rewarded/interstitial рекламы;
- sticky banner-заглушка;
- яркая arcade-оболочка: игровой главный экран, обновленные карточки уровней, гаража, миссий и модалки;
- процедурный Canvas-двор с асфальтом, парковочной разметкой, бордюрами, подсветкой выезда, маршрутами actors и warning-состоянием лимита ходов;
- внутренняя оценка сложности уровня: `minMoves`, `difficultyScore`, `difficulty`;
- анализатор показывает не только dependency-ходы, но и `revisits`: сколько раз решение требует возвращаться к уже двигавшимся машинам;
- валидатор уровней ловит простые target-line решения, проверяет source metadata, размеры паков, прогрессию сложности и нелинейность classic-паков;
- валидатор daily-уровней на ближайшие даты.
