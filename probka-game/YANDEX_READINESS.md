# Готовность к публикации на Яндекс Играх

Аудит интеграции SDK по коду (`yandex-sdk.js`, `game.js`, `ads.js`, `progress.js`, `audio.js`).
Живая документация Яндекса в этой среде недоступна — пункты сверены с известными
требованиями площадки; помечено, что стоит перепроверить вручную перед заливкой.

## Локализация и медиа (актуальное состояние)

- **Игра двуязычная RU/EN.** Переключатель в Настройках (persist `settings.lang`),
  язык по умолчанию берётся из `ysdk.environment` (иначе RU). При заливке можно
  заявить в Консоли обе локали — `ru` и `en`. Весь UI переводится (проверено по
  всем экранам, включая туториал, гараж, дейли, статистику, модалки).
- **Иконка/обложка/скриншоты** — актуальные файлы в `releases/yandex-assets/`:
  `icon-512.png` (квадрат без скруглений), `cover-800x470.png` (иллюстрация),
  `screen1-night.png … screen6-rainy.png` — **1350×2400 (ровно 9:16,
  длинная сторона 2400 ≤ 2560)**, 24-bit PNG, RU, 100% полнокадровый
  геймплей без рамок. Иконка/обложка — новый концепт «Побег героя».
- **Звук**: эффекты через фильтр-шину + опциональная казуальная фоновая
  музыка **только во время геймплея** (тумблер в Настройках, по умолчанию выкл).
- **Скриншоты перегенерированы** под текущую сборку (фикс заголовка уровня,
  тени машин, свечение выезда, токен-иконка/чип серии в шапке).

## Полировка релиз-сессии (что изменилось)

- **Валюта**: монеты → **жетоны (парковочные)**, новая глянцевая SVG-иконка
  (золотой жетон с рулём); суммы показываются как «число + иконка».
- **Экономика пересобрана** (`config.js` rewards, `texts.js` миссии):
  щедрее в начале, серия сильно поощряет ежедневный заход; цены скинов/дворов
  без изменений. Подсказки/пропуски — за рекламу, не за жетоны.
- **Главное меню**: минималистичный герой «Уровень N + Играть», чип серии 🔥
  в шапке (виден на всех экранах, серия стартует с 1).
- **Вкладка «Уровень дня»**: настоящий календарь по дням недели, прогресс
  месяца, золотые пройденные дни со звёздами, подсветка «сегодня».
- **Настройки** вынесены отдельной вкладкой; **обучение** переписано (тур по
  разделам с прожектором); **превью дворов** — реальные кадры арта.
- **Шрифты** self-hosted (Inter + Nunito, офлайн). Рантайм ≈ **21.9 МБ**.

## Сделано (QA-проход)
- **i18n.js включён в сборку релиза**: файл был в `syntaxFiles`, но отсутствовал в
  `baseRuntimeFiles` и regex `applyCacheVersion` → пересобранный архив отдавал бы 404
  на `i18n.js` и ломал английский. Добавлен в оба места (проверено пересборкой архива).
- **Скриншоты приведены к 9:16**: было 1290×2640 (пропорция ≈1:2.05 и длинная сторона
  2640 > лимита 2560) → стало **1350×2400** (ровно 9:16, в пределах 1280–2560).
  Константы в `tools/generate-yandex-assets.js` обновлены.
- **Грамматика склонений**: «Июль 31 уровней» → «31 уровень» (helper `formatLevelCount`,
  RU 3-форма / EN 2-форма).
- **Тулбар**: бренд больше не обрезается (адаптивный перенос), языковой чип — компактный круг.

## Сделано ранее (ночной проход)
- **Размер архива: 50.2 → 21.1 МБ** (PNG пожаты pngquant+optipng без потерь) — снят главный риск веса.
- **Interstitial-троттлинг по времени**: минимум 60 с между роликами (`MIN_INTERSTITIAL_INTERVAL_MS`).
- **blur/focus-хендлеры**: надёжная пауза/mute на мобильных и в WebView Яндекса.
- **updateGameplayMarker в stopTimer**: сигнал GameplayStop стал безусловным.
- **applyPlatformLanguage**: убран мёртвый no-op-тёрнари.

## Рекомендации (продуктовые решения — на усмотрение владельца)
1. **Sticky-баннер**: API готов (`showBanner/hideBanner`). Включение = доход, но занимает место на экране — решить по вёрстке. Вызвать `yandex.showBanner()` в `initializePlatform()` после init.
2. **Чистка репозитория**: `assets/yards/*/source` и `*/qa` (~76 МБ AI-исходников и QA-монтажей) не входят в рантайм. Можно удалить из ветки для лёгкого репозитория (восстановимо из истории).
3. **Перед заливкой**: прогнать черновик в Консоли с `debug-mode=16` и подтвердить Game Ready, rewarded/interstitial, cloud-save на реальном устройстве.

## ⚠️ Сборка архива перед публикацией — ВАЖНО
- В репозитории лежит **старый** `releases/probka-yandex-1.0.0.zip` (~49.6 МБ, собран до ночной оптимизации). **Не заливать его** — это неоптимизированная версия со старыми тяжёлыми PNG.
- Актуальный рантайм весит **21.12 МБ** (проверено `release-yandex.js --runtime-only`). Архив будет ≈этого размера — втрое меньше старого и с запасом под лимит площадки.
- Пересобрать архив перед заливкой:
  - Полная сборка `node probka-game/tools/release-yandex.js` пересобирает банк уровней из сырых датасетов в `probka-game/data/` (gitignored). Если их нет локально — шаг падает с `not enough candidates` (это не баг рантайма, `level-bank.generated.js` уже валиден и используется игрой).
  - Без пересборки банка: `node probka-game/tools/release-yandex.js --skip-checks` (предварительно убрать старую `releases/probka-yandex-1.0.0/` и `.zip`).
- Рекомендация: не коммитить бинарные release-архивы в репозиторий (старый zip + 3 backup-папки в `releases/` уже занимают ~120+ МБ истории) — собирать локально при заливке.
