# Промо-ролик для Яндекс Игр

`promo-9x16.mp4` — вертикальный рекламный монтаж игры.

- **1080×1920 (9:16)**, 13.3 c, H.264 + AAC, ~3 МБ, `+faststart`.
- Структура: титул → 4 геймплейных кадра с плашками (двор/режимы/ежедневка) → CTA «Играть · на Яндекс Играх».
- Лёгкий Ken Burns-зум на кадрах, кроссфейды между сегментами.
- Музыка синтезирована из реальной аккордовой прогрессии игры (C–G–Am–F), чтобы звучать «как игра».
- Кадры собраны из настоящих скриншотов геймплея (брендовый топбар скрыт, как в требованиях к скринам).

## Как добавить в Яндекс
Консоль разработчика → карточка игры → поле видео/трейлера.
Яндекс принимает ссылку на видео (напр. YouTube) или загрузку файла —
этот mp4 совместим с обоими вариантами.

> Это промо-монтаж из кадров, а не запись реального прохождения в реальном времени.
> Если позже понадобится «честный» геймплейный клип с живым движением фишек —
> его тоже можно отрендерить (через авто-решение уровня покадрово).
