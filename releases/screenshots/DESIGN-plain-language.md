# Singularity Inc. — Понятность: простые слова + ясность для новичка (концепт)

> Заказчик дал поиграть друзьям → «не понимают, что происходит». Термины слишком профессиональные. ПРАВИЛО: **то, что ПОКУПАЕШЬ — остаётся крутым** (сервер = сервер, GPU-риг = GPU-риг; НЕ «станция хранения данных»). А **жаргон механик/метрик → простые, интуитивные слова.**

## 1. Что НЕ трогаем (крутой флавор покупок)
Ноутбук · GPU-риг · Серверная стойка · GPU-кластер · Датацентр · Суперкомпьютер · Нейро-массив · Модель v1…AGI. Это «вкусная» часть — оставляем как есть.

## 2. Глоссарий: ЖАРГОН → ПРОСТО (предложение)
| Сейчас (жаргон) | Предлагаю (просто) |
|---|---|
| Runway | **«Денег хватит на: N дней»** |
| Burn / расход | **«Траты»** |
| Valuation | **«Стоимость компании»** |
| Compute | **«Мощность»** (вычислительная мощь ИИ) |
| Market share | «Доля рынка» (оставить — понятно) |
| Model generation / поколение | **«Версия ИИ»** (v1, v2, v3…) |
| Funding round / Seed / Series A | **«Раунд инвестиций»** (Посевной → Раунд 1/2/3 → IPO) или «Привлечь инвесторов» |
| Mandate (управляющий) | **«Курс»** (рост/баланс/безопасность/доля) |
| Standings | **«Рейтинг компаний»** |
| Boost | **«Ускорение»** |
| Incident Risk / Safety | уже просто (Фаза 5) — оставить |
| Trust | **«Одобрение населения»** (уже решили) |
| Prestige / Legacy | **«Новая компания (с наследием)»** |

(Не финал — пройдись, поправь формулировки на свой вкус.)

## 3. Каждая метрика/ресурс — ОДНА простая фраза-подсказка
По тапу/наведению на любой показатель — объяснение в одну строку без жаргона:
- Мощность: «Сила твоего ИИ. Больше мощности → больше доход и быстрее новые версии.»
- Денег хватит на: «Сколько продержишься при текущих тратах. Дойдёт до 0 — долги и банкротство.»
- Одобрение населения: «Что люди думают о тебе. Высокое → рост и найм; низкое → бойкоты и регуляторы.»
- и т.д. для всех.

## 4. Всегда видна СЛЕДУЮЩАЯ ЦЕЛЬ (простыми словами)
Постоянная подсказка «Сейчас делай: …» — чтобы новичок не терялся:
- «Жми на ядро → копи Мощность» → «Накопил — выпусти первую Версию ИИ» → «Версия вышла — пошёл доход, докупай железо» → «Следи за счетами и долей рынка» …
Ведём игрока за руку первые минуты простым языком.

## 5. Обучающие окна (teach-on-first) — на простом языке
Все объяснялки (счёт за свет День 7, налоги День 30, первый инцидент, первый раунд) — **простыми словами, без терминов**, с «что это / что делать / что будет если забить».

## 6. Принцип для ВСЕХ текстов
- Короткие предложения, бытовые слова.
- Каждая новая механика — объяснена в момент появления.
- Числа с понятными подписями и знаком.
- Тест: «понял бы человек, видевший только ChatGPT/совсем не игравший».
