## 1. Видение / стержень
Ты — основатель AI-лаборатории. Путь: **гараж → стартап → frontier-лаба → AGI.** Одна фантазия: **растить свою AI-компанию** (как Anthropic / OpenAI). Каждая механика существует, чтобы служить этому. **Модели — расходник; КОМПАНИЯ — герой, который растёт навсегда.**

Это отвечает на «продал модель — и что?»: ты не копишь абстрактные очки, ты **строишь компанию.**

## 2. Три (+1) петли — как устроена игра
1. **Тренировка** (секунды–минуты): тапаешь + покупаешь компьют (генераторы) → растёт выпуск и деньги → покупаешь ещё → выпуск растёт.
2. **Релиз модели** (~30–60 мин): рост упёрся → **выпускаешь модель** → тренировка сбрасывается, ты получаешь **Влияние** — постоянный прогресс компании, пропорционально успеху забега.
3. **Компания** (навсегда): тратишь Влияние на **департаменты** — перманентные апгрейды + новые механики/вкладки. Компания сильнее → следующая модель тренируется быстрее и крупнее.
4. **Сингулярность** (эндгейм): компания достигает AGI → глубокий ресет → **Ядра** + мета-дерево + концовка.

## 3. Валюты — у каждой чёткая роль
- **💵 Деньги (Cash)** — валюта ЗАБЕГА: генераторы, апгрейды забега. Сбрасывается при релизе.
- **✨ Влияние (Influence)** — даётся за релиз модели; **ПОСТОЯННОЕ**. +X% к выпуску навсегда + открывает и качает департаменты. Это «топливо роста компании» (переосмысление нынешнего RP).
- **🌀 Ядра (Cores)** — эндгейм (Сингулярность), глубокий мета-слой.

Чёткая лестница: **Деньги (забег) → Влияние (компания) → Ядра (финал).**

## 4. Компания = департаменты (= вкладки, открываются ПО ПОРЯДКУ)
Каждая нынешняя система получает «дом» и понятную роль внутри компании:

| Департамент | Бывшая система | Зачем нужен | Когда открывается |
|---|---|---|---|
| 🧪 **Research Lab** | дерево исследований | качество и множители моделей | после 1-го релиза |
| 🖥 **Infrastructure** | компьют-множители, автопилот | масштаб производства | рано, по объёму компьюта |
| 👥 **Talent / Найм** | менеджеры, баффы | люди = выпуск | по мере роста |
| 🛡 **Safety / Alignment** | риск-векторы + кризисы | держать риск масштаба | после 1-го релиза |
| 💼 **Business / Funding** | бывш. «рынок» → раунды + оценка | деньги и рост компании | позже |
| 📣 **Comms / Policy** | новости + Доверие | публичное восприятие, регуляторы | позже |

Принцип «сделал X → открылась вкладка Y» становится **буквальной структурой игры.**

## 5. Порядок открытия (лестница департаментов)
1. **Гараж:** только тренировка (тап + 1 генератор).
2. **Scaling:** генераторы, режимы покупки, milestone, Infrastructure (база).
3. **Automation:** Talent (менеджеры) + автопилот.
4. **Первый релиз:** обучающий момент → открывается **Research Lab** + Влияние.
5. **Риски масштаба:** открывается **Safety / Alignment** (риск начинает копиться только теперь).
6. **Индустрия:** открывается **Business/Funding** и **Comms/Policy** (финансы, оценка, новости, доверие).
7. **Эндгейм:** Сингулярность + концовки.

## 6. КАРТА СВЯЗЕЙ — как компоненты влияют друг на друга
- Компьют → выпуск → Деньги → ещё компьют. *(петля 1)*
- Успех забега → при релизе → **Влияние.** *(петля 2)*
- Влияние → департаменты → перм-множители + разблокировки → быстрее следующий забег. *(петля 3)*
- **Скорость роста** (компьют/выпуск) → растит **Риск** → Safety-департамент его гасит; забил → **кризис** (штраф/эскалация). Это центральный тредофф «гнать vs безопасность».
- Решения и публичность → **Доверие** (Comms) → гейтит контент (госконтракты и т.п.) и двигает **оценку компании.**
- **Оценка (valuation)** растёт от прогресса, реагирует на новости/доверие/кризисы; открывает раунды финансирования и влияет на концовку.
- **Конкуренты** (Race to AGI) растут параллельно → создают давление и дедлайн.
- Всё ведёт к **AGI → Сингулярность → концовка**, зависящая от того, КАК ты рос (безопасно / безрассудно / зарегулировали / обогнали).

## 7. Рынок → «Финансирование и оценка» (переделка кривого рынка)
Убираем твичевый buy-low/sell-high. Вместо него:
- **Раунды (Seed → A → B → C → IPO):** разовая инъекция денег в обмен на **долю % будущей стоимости** (тредофф: кэш сейчас vs. больше % потом). Решение, а не дёрганье.
- **Оценка компании (valuation):** живая, растёт с прогрессом, реагирует на новости/доверие/кризисы; предмет гордости; гейтит часть контента/концовок.

## 8. Safety / Alignment
Тематически — твоя **команда безопасности.** Несколько векторов риска от разных активностей; вкладываешься заранее (проактивно) → меньше и слабее кризисы; кризис = карточка-решение с тредоффами; игнор → эскалация. (Механика уже сделана в Фазе 2 — здесь только «дом» = департамент Safety.)

## 9. Нарратив
Акты = стадии компании (Гараж→Стартап→Frontier→Гонка→Сингулярность). Конкуренты = гонка к AGI. Концовки = как именно ты дошёл (Aligned / Reckless / Nationalized / Beaten to AGI). Новости/тикер — голос мира, реагирующий на тебя.

## 10. Эндгейм
**Сингулярность:** компания достигает AGI → глубокий ресет (сбрасывает и Влияние) → **Ядра** + мета-дерево с сильными модификаторами → одна из концовок. Реиграбельность: гнаться за другими концовками другой стратегией.

## 11. РАЗВИЛКИ — выбери вариант (остальное я решил сам)

**A. Валюта компании**
- **A1 (рекомендую):** ОДНА — «Влияние». Просто и понятно.
- A2: ДВЕ — Деньги/Funding + Репутация. Больше решений, но сложнее новичку.

**B. Релиз модели (сброс)**
- **B1 (рекомендую):** полный ресет забега, компания сохраняется. Классика, «вес» релиза чёткий.
- B2: мягкий — сохраняешь часть прогресса. Дружелюбнее, но размывает значимость релиза.

**C. Рынок / финансы**
- **C1 (рекомендую):** Раунды финансирования + Оценка компании.
- C2: упрощённый рынок (1–2 актива, без эксплойтов) + Оценка.
- C3: пока вырезать трейдинг, оставить только Оценку.

**D. Масштаб переработки**
- **D1 (рекомендую):** полный реврайт — RP→Влияние, перевес систем в департаменты, безопасная миграция сейвов.
- D2: лёгкий — структуру не трогаем, только переименовать/связать нарративом + починить рынок.

## 12. Что НЕ трогаем
Ядро тренировки (тап+генераторы), баланс из Фазы 2, прогрессивные анлоки, понятность покупок — это уже хорошо; реврайт идёт ПОВЕРХ, не ломая это.
