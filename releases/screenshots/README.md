# Скриншоты и медиа для Яндекс Игр

Обычные скриншоты **каждого окна** игры (без композитов/превью).
Везде подсеян реалистичный прогресс: серия 7, 82 уровня пройдено, золотой
календарь (14/30), баланс 1340 жетонов — не пустой аккаунт.

## Мобильные (9:16, 1350×2400) — вертикальная раскладка
- `mobile-01-menu` — главное меню
- `mobile-02-gameplay` — геймплей (ночной двор)
- `mobile-03-levels` — список уровней
- `mobile-04-daily` — уровень дня (календарь)
- `mobile-05-garage` — гараж
- `mobile-06-missions` — миссии
- `mobile-07-stats` — статистика
- `mobile-08-settings` — настройки
- `mobile-09-modes` — выбор режима
- `mobile-10-gameplay2` — геймплей (неоновый двор)

## Десктоп (16:9, 1920×1080) — горизонтальная раскладка
Те же 10 окон: `desktop-01-menu` … `desktop-10-gameplay2`.
- Геймплей (`02`, `10`) — в реальной широкоэкранной раскладке (доска слева, HUD справа).
- Меню и разделы — как игра выглядит на десктопе: центрированная колонка
  на тёмном фоне приложения (это родная десктоп-раскладка, не обрезка).

## Иконка и обложка
- `icon-512.png` — иконка игры 512×512 (RGB, без альфы, квадрат)
- `cover-800x470.png` — обложка/баннер 800×470

Загружать: десктоп → «горизонтальные» слоты, мобильные → «вертикальные»,
иконку и обложку — в соответствующие поля карточки.
