# Скриншоты для Яндекс Игр

Набор показывает **функционал** игры (а не только геймплей с разными дворами).
Данные на экранах подсеяны реалистичным прогрессом (серия 7, 82 уровня пройдено,
календарь с золотыми днями, баланс 1340 жетонов) — не пустой аккаунт.

## Мобильные (9:16, 1350×2400) — вертикальная раскладка
- `mobile-1.png` — **главное меню** (уровень, серия, баланс, плитки разделов)
- `mobile-2.png` — геймплей: ночной двор
- `mobile-3.png` — **уровень дня**: календарь 365 вызовов, серия, золотые дни
- `mobile-4.png` — **гараж**: машины и дворы (косметика)
- `mobile-5.png` — геймплей: неоновый двор
- `mobile-6.png` — **статистика**: уровни, звёзды, серии, прогресс по режимам
- `mobile-7.png` — **миссии**: ежедневные цели с наградами

## Десктоп (16:9, 1920×1080) — горизонтальная раскладка
- `desktop-1.png` — геймплей: ночной двор (доска слева, HUD справа)
- `desktop-2.png` — витрина: главное меню
- `desktop-3.png` — геймплей: неоновый двор
- `desktop-4.png` — витрина: уровень дня
- `desktop-5.png` — витрина: статистика

Геймплейные кадры — с настоящего экрана игры (брендовый топбар скрыт,
геймплей ≥70%). Десктоп-витрины функционала собраны как app-store-композиты
(портретный экран в рамке телефона на брендовом фоне), потому что в реальной
десктоп-раскладке меню — узкая центрированная колонка с пустыми боками.

Загружать: десктоп → «горизонтальные» слоты, мобильные → «вертикальные».
