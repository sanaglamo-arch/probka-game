# Скриншоты для Яндекс Игр

## Десктоп (16:9, 1920×1080) — горизонтальная раскладка
- `desktop-1.png` — ночной двор, на счёт ходов
- `desktop-2.png` — неоновый двор, на время
- `desktop-3.png` — зимний двор, свободный режим
- `desktop-4.png` — лесной двор, на счёт ходов

## Мобильные (9:16, 1350×2400) — вертикальная раскладка
- `mobile-1.png` — ночной двор
- `mobile-2.png` — неоновый двор
- `mobile-3.png` — зимний двор
- `mobile-4.png` — праздничный двор
- `mobile-5.png` — лесной двор
- `mobile-6.png` — дождливый двор

Во всех кадрах геймплей занимает ≥70% площади (брендовый топбар скрыт),
как требует Яндекс. Загружать в соответствующие слоты: десктоп → «горизонтальные»,
мобильные → «вертикальные».
