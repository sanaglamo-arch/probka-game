# Singularity Inc. — КАМПАНИЯ: финальный рабочий концепт

> Управленческое решение (тимлид, по мандату владельца 18.06): кампания-первой, свободный режим — будущее расширение. Заземлено на основах idle-геймдизайна (Hook→Habit→Hobby; D1 35-40/D7 10-15; онбординг прогрессивным раскрытием; мид-гейм против content-desert). Ниже — решения + 2 прохода самокритики. Гейт на код: пруф-сим экономики.

## 0. Рамка
- **Кампания = сфокусированная пробивная история** гараж→AGI. Владеет стадиями Hook (первые 30 мин) и Habit (1-7 дней).
- **Долгий хвост (Hobby, D30) сознательно НЕ цель кампании** — это домен будущего свободного режима. Кампания оптимизирует D1/D7 + «дошёл до концовки» + реиграбельность.

## 1. Длина и время (РЕШЕНО)
- **Normal ≈ 2.5-3 ч активной игры до AGI**, растянуто на **~3-5 реальных дней** офлайн-прогрессом + реал-таймерами обучения.
- **1 игровой день ≈ 60 сек** (возврат к «старой скорости», которую ты назвал). Кампания ~200-250 игр.дней ≈ **под год игрового времени** («из гаража в AGI за год безумного кранча» — правдоподобный стартап-миф, НЕ абсурдные 28 дней).
- Календарь сверху: «14 марта, Год 1, вечер». Дата+время суток (4 периода: утро/день/вечер/ночь), без минут/секунд.
- Бильная каденция при 60с/день: электро-счёт ~ каждые 7 мин (7 дней), налог ~ каждые 30 мин (30 дней).
- **Офлайн-прогресс капнут на ~8-12 ч** = «welcome back»-нудж, не авто-проигрыш игры за тебя: обучение идёт, немного выручки капает, бухгалтер платит счета (комиссия). Агентность (тапы, решения, покупки, гонка) — только онлайн.

## 2. Кор-петля (РЕШЕНО)
Тап TRAIN → копишь **Мощность** → выпускаешь поколение модели → доход растёт → покупаешь железо/Мощность → крупнее модель → … → **AGI**.
Поверх — слои напряжения: недельный счёт (дедлайн), месячный налог, 4 метрики через решения, гонка к AGI с ривалами (HUD отрыва).

## 3. Экономика (ПЕРЕСТРОЕНА — модель счетов)
Полная спека — `DESIGN-bills-rework-FINAL.md`. Кратко:
- **Число сверху = Доход (≥0, никогда не минус)** + ОБЯЗАТЕЛЬНЫЙ сигнал платёжеспособности («след. счёт через 3 дня ≈$188 · касса покрывает ✓/⚠») — лечит «доход маскирует банкротство».
- Расходы копятся → **недельный счёт**: Зарплаты · ⚡Электричество (всё железо, поглотило дубль «compute-burn») · Оверхед. **1 игр.день на оплату**, просрочка → −30% (пол, не 0).
- **Налог** месячный, та же механика, просрочка → Лояльность гос-ва.
- **Мощность = только ресурс** (разделить «Мощность/сек»-мотор и «накоплено»-топливо обучения, teach-on-first); нигде не трата.
- Бухгалтер офлайн платит счета с комиссией.
- 🔒 **ГЕЙТ: пруф-сим под 60с/день** — строить выгодно с v1 (больше железа→больше счёт, но маржа по неделе плюсовая), проходимо 4 сложности, неплатящий/жадный/idle падают, парк-эксплойт мёртв. Без пруфа в код не идём.

## 4. Сложности (РЕШЕНО)
4 уровня (Легко/Норма/Сложно/Невозможно) различаются **давлением и темпом, НЕ гейтингом контента**:
- множители счёта/выручки, стартовая подушка кассы, скорость AGI-ривалов, тяжесть событий (чёрные лебеди), льгота на просрочку.
- Легко = учишься, прощает. Невозможно = мастерство, тонкая маржа. Каждая проходима правильной игрой (доказывает пруф-сим). Чёрные лебеди — урезанный сабсет на Норме/Сложно (телеграф), полный на Невозможно.

## 5. Онбординг / FTUE (РЕШЕНО — заземлено)
- **Прогрессивное раскрытие:** на старте видно только TRAIN. Системы вводятся по мере релевантности: выпустил модель → открывается покупка Мощности → первая неделя → счёт (+обучалка) → первое решение → метрики → ривал раскрыт → HUD гонки.
- **Front-load наград:** TRAIN-juice (слот-машина) + выпуск v1 = кат-сцена → первый дофамин ≤90с.
- **ФИКС −0.02:** до выручки доход = $0 + крупный зовущий CTA «Выпусти первую модель» (не отрицательное число, не наказание до первой победы).
- Teach-on-first попап на каждую систему, минимум наказания во время онбординга.

## 6. Мид-гейм — против «content desert» (РЕШЕНО — главная точка оттока)
Известно, что тут отваливаются. Затыкаем НЕ престижем, а плотностью:
- эскалация счетов/налога; 4-метричные решения с кросс-давлением; **гонка к AGI + HUD отрыва + активность (спринт/саботаж/альянс)**; чёрные лебеди (телеграф); **каждое новое поколение = видимый скачок мощи + новые типы решений + сатира-реакция ривалов**.
- Цель: каждые 2-4 минуты — событие/решение/скачок, не пустое ожидание.

## 7. Эндгейм (РЕШЕНО)
- **AGI = финиш.** Концовки по Safety/метрикам → шеримые карточки. HUD гонки делает финальный рывок напряжённым (обогнать ривалов).
- Кампания короткая → **многодневного слога нет**, финал приходит, пока ещё интересно.

## 8. Удержание / реиграбельность (РЕШЕНО — заместитель престижа)
- **Внутри забега:** офлайн + реал-таймеры обучения + срочность гонки тянут назад.
- **Между забегами (это и есть «престиж» кампании, без сбросов):** лестница сложностей (пройти Сложно/Невозможно) · собрать ВСЕ концовки (Зал славы) · альт-цели (R7: без инцидентов/монополия/спидран) · рейтинг ривалов.
- Сознательный размен: **отдаём долгий хвост (D30) ради чистой завершённой кампании**; долгий хвост = будущий свободный режим.

## 9. ВЫРЕЗАНО (мандат использован — выношу явно, можешь вето)
- 🔪 **Престиж-стек целиком** (RP + артефакты + Singularity Cores + Founder's Legacy) — ИЗ кампании, зарезервирован под свободный режим. Кампания = чистая история без сбросов. Остаются рекорды/Зал славы/коллекция концовок (это персист, не валюта-сброс).
- 🔪 **Дейли-стрик (R7) демонтирован до лёгкого** — полноценный дейли-стрик плохо ложится на проходимую кампанию (добиваешь раньше, чем стрик важен). Оставляем лёгкий «welcome back» + офлайн-отчёт; полный дейли-цикл → свободный режим. Альт-цели (R7) ОСТАЮТСЯ (идеально кормят реиграбельность кампании).
- 🔪 **«Хватит на N дней»** (старый runway) — вычистить, непрерывного burn нет → «след. счёт + покрытие».

- **Счёт каждые 7 мин с окном 60с — не слишком ли жёстко?** → Защита: бухгалтер ловит офлайн, громкий телеграф накопления + обратный отсчёт, первый счёт учит. Окно 1 день — твоя явная спека, оставил.

## ПРОХОД САМОКРИТИКИ #2 (большая картина: это вообще цельно и весело?)
- **Вырезание престижа не убьёт долгое удержание?** Исследование: престиж тянет playtime, НО он же создаёт «content desert». Для проходимой кампании заместитель (лестница сложностей + концовки + альт-цели) уместнее; D30 честно отдаём свободному режиму. Разъяснил размен явно (§8).
- **Дейли-стрик vs проходимая кампания** — конфликт жанра. Демонтировал до лёгкого (§9). Коэрентность > невозвратные затраты на R7.
- **Боязнь скучного мид-гейма** (главный отток) — закрыт не обещанием, а конкретикой §6 (событие каждые 2-4 мин). Это реальный фикс «скучного позднего этапа», ради которого всё затевалось.
- **Цельность:** модель счетов + 60с/день + 4 сложности + FTUE-раскрытие + completionist-удержание + без престижа → непротиворечивое целое. Каждая старая боль закрыта (см. предыдущий аудит) или явно открыта (Мощность поток/запас — теперь решено разделением).
