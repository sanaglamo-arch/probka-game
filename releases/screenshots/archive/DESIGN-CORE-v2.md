# Singularity Inc. — КОР v2 (синтез на базе видения владельца)

> Решения тимлида по мандату «реши сам». База — `DESIGN-VISION-owner.md`. Это полная картина новой версии.

## Кор-петля (одним взглядом)
Клик (бутстрап) → деньги → покупаешь **железо** (сдаётся в аренду = пасс. доход) + **помещения** (м² = место под железо) → копишь **Мощность** → **выпускаешь модель** → железо перестаёт арендоваться, начинает крутить твою модель → **ставишь цену токенов** → мощность÷цена даёт **долю рынка** → доход = цена × доля × спрос → строишь дальше → **следующая версия** (скачок мощности) → … → **AGI = финальная версия = победа.**

## 1. СЕРДЦЕ: цена токенов → доля → доход (РЕШЕНО: симуляция под слайдером)
- Ценность V = **Мощность ÷ Цена**. Доля рынка = V / (V + ΣV_ривалов). Доход = Цена × доля × Спрос. Себестоимость = электричество за обслуженные токены + счета.
- Три зоны его сложностей возникают сами: слишком дёшево → доля есть, но цена×объём < себестоимость → минус; сладко → доля × маржа максимум; слишком дорого → V падает → доля рушится + **общество злится** (гуджинг).
- **Подача:** простой слайдер цены с живым превью («при этой цене → доля 23%, прибыль +$X/с, одобрение ↓»). Глубина под капотом, поверхность читаемая.
- **Взаимодействие:** ставишь цену на релизе + **перетюниваешь редко**, когда игра подсказывает («Helion выпустил мощнее — твоя доля скользит, проверь цену»). Не задрачиваешь слайдер.
- Сладкая точка ДРЕЙФУЕТ: растёт твоя Мощность → можешь дороже; ривал выпустил мощнее → режь цену или гони мощность; спрос растёт по эрам. → переоткрываемое решение.

## 2. Параметры (РЕШЕНО: 2 эконом-показателя + 3 метрики-риска)
- **Эконом-показатели (что оптимизируешь, видны всегда):** Мощность · Деньги/Ликвидность (касса+прибыль) · Доля рынка.
- **3 метрики-риска (0-100), каждая = свой путь поражения:**
  - **Безопасность** — риск/элайнмент → аварии + питает гнев государства + элайнмент-концовка.
  - **Одобрение общества** — → отмена.
  - **Государство & закон** (слил его «государство»+«закон» в одну) — → запрет / иски / национализация.
- Сотрудники мапятся 1:1: безопасник→Безопасность, маркетолог→Одобрение, юрист→Государство&закон, экономист→налоги(→Ликвидность). Помогают, но не обнуляют.

## 3. Многопоколенность (РЕШЕНО: одна эволюционирующая флагман-модель)
- Всегда ОДНА текущая модель, зарабатывает через токены.
- Чтобы развить СЛЕДУЮЩУЮ версию — строишь ещё железо/помещения. **Новое железо в разработке сдаётся в аренду** (бридж-доход), пока не выпустил.
- **Выпуск vN+1:** Мощность скачком (всё железо теперь в продакшене), аренда нового железа прекращается, доля/доход пересчитываются, перетюнил цену.
- Строить выгодно ДВАЖДЫ: аренда сейчас + крупнее модель потом. AGI = финальная версия.

## 4. «Модель исчезает» (РЕШЕНО: откат, не мгновенная смерть — кроме краёв метрик)
- **Пожар** (низкая физ-безопасность помещения): теряешь помещение+железо → Мощность/доход падают → восстанавливайся (отстрой/раунд). Удар, не смерть. Телеграф = твой %.
- **Совет директоров** (долгая низкая ликвидность): сначала ПРЕДУПРЕЖДЕНИЕ (совет требует прибыльности), затем при критич. ликвидности → форс-продажа = гейм-овер. Совет «появляется не сразу» = грейс.
- **Гейм-овер только на полах метрик** (запрет/отмена/иски/банкрот), всё телеграфируется до самого низа. Рычаг есть всегда.

## 5. Помещения (РЕШЕНО: 5 параметров, но легальность+безопасность = один «класс»)
- Показ: размер (м²) · цена · обслуживание ($/с) · **риск-профиль** («Подвал — дёшево, законность 60%/безопасность 55%» ↔ «Бизнес-парк — дорого, 98%/95%»).
- Один выбор «насколько легитимно место» с двумя прозрачными последствиями (законность→иски, безопасность→пожар). Не перегруз.

## ДОРАБОТКИ поверх твоего концепта
- **R1 Клик:** рано — основной доход (бутстрап), позже — лёгкий буст (хук не умирает, но не обязателен).
- **R2 «Фикс или растёт доход модели?»** → РЕШЕНО: ни то ни другое — доход ДИНАМИЧЕН через цену×долю×спрос. Растёт от роста спроса/доли/версии, падает если ривалы обходят. Твой открытый вопрос закрыт самой моделью.
- **R3 Счета:** все периодические расходы (электричество железа + обслуживание помещений + зарплаты + налог) копятся в счёт с дедлайном (твоя прежняя локи: электро недельно, налог месячно, доход ≥0 не минусует). Ликвидность = покрываешь ли счета.
- **R4 Сложности (4):** различаются агрессией ривалов, размером спроса, тяжестью событий при том же %, стартовой кассой, налогом, терпением совета. Каждая проходима (пруф-сим).
- **R5 Онбординг:** твоя стартовая цепочка $50→клик→мини-сервер дословно. Прогрессивное раскрытие: аренда объясняется на первом сервере; цена/доля открываются на ПЕРВОМ релизе; метрики/помещения — по мере перерастания комнаты.
- **R6 Ривалы:** выпускают свои модели, ставят свои цены, тянут долю. Твоя доля относительна. Гонка к AGI = кто первый выпустит финальную версию. Рейтинг компаний по доле = и конкуренция, и AGI-гонка в одной системе.
- **R7 Из старого билда переживают:** сатира-тикер, концовки+шеримые карточки, альт-цели, бухгалтер (офлайн-счета), раунды/IPO (капитал), дата/время-HUD. Решения-движок легчает (события теперь следствие %-ов + меньший набор флавор-дилемм). Престиж-стек, биржа — вырезаны.
