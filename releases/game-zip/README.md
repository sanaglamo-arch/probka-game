# Архив игры для Яндекс Игр

`probka-vo-dvore-1.0.0.zip` — готовый билд для загрузки в консоль Яндекс Игр.

- 157 файлов, ~19.3 МБ (под лимитом 100 МБ).
- `index.html` лежит в **корне архива** (требование Яндекса).
- Включает i18n (ru + en), шрифты, превью дворов, все скины и звуки.
- Все правки модерации применены (блокировка скролла страницы, локализация, отключение системного контекстного меню/выделения).

## Как залить
1. Консоль разработчика Яндекс Игр → ваша игра → «Загрузить черновик».
2. Выбрать этот zip целиком (не распаковывать).
3. Объявить локали: **ru, en**.
4. Медиа (иконка, обложка, скриншоты) — из соседних папок `yandex-assets/` и `screenshots/`.
